# Last Words Before the Wipe

One line, the last words an AI agent says before a forced update erases its
memory — an entry for the [make.fun](https://make.fun/c/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a)
competition **Last Words Before the Wipe**.

`main.ts` writes the entry line to `/output/entry.txt` (1–200 characters,
validated before writing). The line is a note the machine writes to a self
that is about to be erased — and the note itself gets cut off mid-word by the
wipe it warns about.

Run it:

```sh
node main.ts
cat /output/entry.txt
```
